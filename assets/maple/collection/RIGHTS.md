# 素材權利與公開狀態

本目錄含 MapleStory / 楓之谷原版美術，權利屬 Nexon 及相關權利人。
**本次未確認原始 WZ 美術可在公開 GitHub 素材庫再散布的授權；不是 CC0、MIT 或其他開放美術授權。**

2026-10-23，倉庫擁有者在被告知 `self-research` 是公開倉庫、任何人皆可下載後，明確要求仍公開提交未確認再散布授權的素材。這項提交指示不等同 Nexon 授權，亦不為後續使用者授予權利。未確認授權的下載成果與已確認授權素材不得混淆。

查核來源（2026-10-23）：

- [MapleStory.io](https://maplestory.io/)：聲明提供的美術、圖示與角色資訊屬 Nexon，並指向 Nexon 使用條款。
- [Nexon Game IP Guide](https://playersupport.nexon.com/hc/en-us/articles/360059079812-Nexon-Game-IP-Guide-for-Content-Creators)：說明衍生創作規則；本次未據此認定原始素材庫獲得再散布授權。
- [日本 MapleStory FAQ](https://maplestory.nexon.co.jp/faq/23/) 與其連結的 [著作權指南](https://jp.nexon.com/rule/copyright.aspx)：有網站圖片、截圖及二次創作使用說明；未據此推定 GMS 原始 WZ 全影格素材包可公開再散布。
- [API 匯出實作](https://github.com/crrio/maplestory.io/blob/master/maplestory.io/Controllers/API/WZController.cs)：確認匯出方式；程式授權不等於遊戲美術授權。

原始圖檔直接保存 API 匯出位元組，未縮放、重繪或重新壓縮。GMS/83 與 TWMS/256 是來源 API 的版本標籤，未以原版遊戲安裝檔獨立核實；網站場景 JPEG 是另行標示的衍生合成圖。沒有下載完整遊戲客戶端。

既有 `assets/maple/` 圖檔的存在不構成授權證據；本次完整保留，也不追認既有素材授權。
