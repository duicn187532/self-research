    FadeMem：仿生遺忘機制讓 Agent 記憶更有效率

    雙層記憶搭配重要性調節的衰減、LLM 衝突解決與記憶融合，LoCoMo 上減少 45% 儲存。
  • arXiv 2501.13956Agent 記憶已對照全文

    Zep：用時序知識圖譜打造 Agent 記憶

    三層知識圖譜搭配雙時間軸，事實被推翻時標記失效而不刪除；LongMemEval 上延遲降約 90%。
  • arXiv 2605.06527Agent 記憶評測已對照全文

    STALE：LLM Agent 知道自己的記憶過期了嗎？

    400 個隱性衝突情境、三種探測方式；最好的模型只有 55.2%，Zep 只有 6.0%。附原型系統 CUPMem。
  • arXiv 2606.30306綜述已對照全文

    永遠在線的 Agent：持久記憶、狀態與治理綜述

    把分析單位從記憶換成持久狀態：六個軸、十階段生命週期、五個不變量，435 篇語料顯示回滾只有 27 篇。附 AOEP 評測協議。
  • arXiv 2608.19652評測＋方法已對照全文

    StateMem：Agent 記憶系統追得上不斷變動的狀態嗎？

    找得到不等於用對版本。StateMemBench 用事件程式造出 234 個陷阱情境，StateMem 以依賴圖標記過期狀態；只改回答提示詞的包裝器就讓六個後端各進步 32–67 個百分點。
  • arXiv 2604.14362記憶系統已對照全文

    APEX-MEM：只增不刪的屬性圖記憶，查詢時再解析

    事實錨定在有時間的事件上、從不覆寫，回答時由會寫 SQL 的代理挑出有效版本。LoCoMo 88.88%、LongMemEval 86.2%；本頁驗算出多處表格對不上。
  • AI Journal 1986經典已對照全文

    ATMS：以假設為基礎的真值維護系統

    de Kleer 1986。每筆資料標上「在哪些假設下成立」，矛盾只是一個 nogood，多個互斥的解可以並存。四十年後 LLM 記憶論文的許多想法都在這裡。

每篇的讀法

  1. 第一遍：摘要、架構圖、結論。能一句話講出問題、方法、成果。
  2. 第二遍：方法章節。每條公式的每個符號都說得出意思，互動圖自己調一次。
  3. 第三遍：實驗與消融。挑毛病，把疑問寫進筆記，最後匯出。
